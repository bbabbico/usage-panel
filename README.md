# usage-panel

Claude Code 모드: 컨텍스트 사용량, 요금제 한도(5시간/주간), 세션 비용을 패널로 보여줍니다.

Claude Code v2.1.302에서 테스트했습니다.

## 설치

```
claude plugin marketplace add <GitHub계정>/usage-panel
claude plugin install usage-panel@usage-panel
```

## 사용

- 세션을 시작하면 패널이 자동으로 열립니다 (터미널 폭 144칸 이상일 때).
- `/usage-panel` 로 열기/닫기.

## 업데이트

```
claude plugin update usage-panel@usage-panel
```
